# TRIBRIAN TECHNOLOGIES website

A responsive one-page company website built with Next.js, React, and Lucide icons.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

### Easiest method: GitHub

1. Create or sign in to a GitHub account.
2. Create a new repository named `tribrian-technologies-website`.
3. Upload the contents of this folder to the repository (upload the files and folders inside this project, not the ZIP file itself).
4. Visit https://vercel.com and sign in using GitHub.
5. Select **Add New → Project**, then import `tribrian-technologies-website`.
6. Keep the detected framework as **Next.js** and leave the build settings at their defaults.
7. Select **Deploy**. Vercel will build the site and provide a public `*.vercel.app` address.

## Before sharing publicly

- Replace `hello@tribriantechnologies.com` in `app/page.jsx` with the business email you want clients to use.
- Confirm that all listed services and technologies reflect what your team can actually deliver.
- The portfolio section currently describes capabilities rather than claiming completed client projects.
- A custom domain is optional; the Vercel subdomain is sufficient to start.
"# tribrian-technologies"
